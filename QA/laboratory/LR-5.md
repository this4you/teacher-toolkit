---

## 🎯 Мета роботи
Навчитися:
- розрізняти **функціональне** та **нефункціональне** тестування
- створювати тест-кейси для різних типів вимог
- класифікувати тестові сценарії
- розуміти вплив якості системи на користувацький досвід

---

## 🧠 Опис системи (уявний застосунок)

### **Online Course Platform**
Веб-застосунок для онлайн-навчання студентів.

### Короткий опис системи:
Платформа дозволяє користувачам реєструватися, переглядати каталог курсів,
записуватися на курси, дивитися відео-лекції, проходити тести та керувати
власним профілем.

### Основний функціонал:
- реєстрація та логін користувача
- перегляд каталогу курсів
- запис на курс
- перегляд відео-лекцій
- проходження тестів
- профіль користувача

## 📌 Завдання 2. Нефункціональне тестування

### Завдання:
1. Створіть **3 нефункціональні тест-кейси** з різних категорій.
2. Для кожного тесту вкажіть:
    - тип нефункціонального тестування (продуктивність, безпека, юзабіліті тощо)
    - критерій успішності

---

## 📌 Завдання 3. Класифікація тестових сценаріїв

### Завдання:
Для кожного сценарію визначте:
- чи є він **функціональним** або **нефункціональним**

### Сценарії:
1. Користувач не може отримати доступ до платного курсу без оплати
2. Сторінка курсу завантажується менш ніж за 3 секунди
3. Неможливо записатися на курс без авторизації
4. Відео-лекція відтворюється без помилок після оплати
5. Користувач успішно реєструється з валідними даними
6. Система не дозволяє пройти тест без проходження лекції
7. Сайт коректно відображається на мобільних пристроях
8. Система витримує 1000 одночасних користувачів без падінь
