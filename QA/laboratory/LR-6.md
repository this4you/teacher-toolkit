# 🧪 Лабораторна робота
## Тестування API (REST, JSON, HTTP) з використанням Postman

---

## 🎯 Мета роботи
Навчитися:
- розуміти основи **REST API**
- працювати з **HTTP-методами** (GET, POST, PUT, DELETE)
- аналізувати **JSON-відповіді**
- тестувати API за допомогою **Postman**
- перевіряти статус-коди та структуру відповіді

---

## 🧠 Опис системи

У цій лабораторній роботі використовується **публічний тестовий API**, який спеціально створений для навчання та тестування.

### API:
**JSONPlaceholder**  
Base URL: `https://jsonplaceholder.typicode.com`

Це фейковий REST API, який імітує роботу бекенд-сервісу та дозволяє виконувати CRUD-операції.

### Доступні ресурси:
- `/posts`
- `/comments`
- `/users`
- `/todos`

❗ Дані не зберігаються реально — API призначене **тільки для тестування**.

## 🛠 Інструменти
- Postman
- Браузер
- JSONPlaceholder API

## 📌 Завдання 1. GET-запит (отримання даних)

### Завдання:
1. Відкрити Postman
2. Створити **GET-запит** до:
   ```
   https://jsonplaceholder.typicode.com/posts
   ```
3. Надіслати запит

### Перевірити:
- статус-код відповіді = `200 OK`
- відповідь у форматі JSON
- відповідь містить список обʼєктів

---

## 📌 Завдання 2. GET-запит з параметром

### Завдання:
1. Виконати GET-запит:
   ```
   https://jsonplaceholder.typicode.com/posts/1
   ```

### Перевірити:
- статус-код = `200 OK`
- у відповіді присутні поля:
   - `userId`
   - `id`
   - `title`
   - `body`

---

## 📌 Завдання 3. POST-запит (створення ресурсу)

### Завдання:
1. Створити **POST-запит**:
   ```
   https://jsonplaceholder.typicode.com/posts
   ```
2. У Body → raw → JSON передати:
   ```json
   {
     "title": "Postman API test",
     "body": "This is a test post",
     "userId": 1
   }
   ```

### Перевірити:
- статус-код = `201 Created`
- у відповіді присутнє поле `id`
- відповідь у форматі JSON

---

## 📌 Завдання 4. PUT-запит (оновлення ресурсу)

### Завдання:
1. Створити **PUT-запит**:
   ```
   https://jsonplaceholder.typicode.com/posts/1
   ```
2. Передати JSON:
   ```json
   {
     "id": 1,
     "title": "Updated title",
     "body": "Updated body",
     "userId": 1
   }
   ```

### Перевірити:
- статус-код = `200 OK`
- дані у відповіді оновлені

---

## 📌 Завдання 5. DELETE-запит (видалення ресурсу)

### Завдання:
1. Створити **DELETE-запит**:
   ```
   https://jsonplaceholder.typicode.com/posts/1
   ```

### Перевірити:
- статус-код = `200 OK` або `204 No Content`
- тіло відповіді порожнє або мінімальне

---

## 📸 Завдання 6. Скріншоти
Зробити **5 скріншотів з Postman**:
1. GET /posts
2. GET /posts/1
3. POST /posts
4. PUT /posts/1
5. DELETE /posts/1

На кожному скріншоті має бути видно:
- URL
- HTTP-метод
- статус-код
- відповідь сервера
