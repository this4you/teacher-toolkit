## 🎯 Мета лабораторної роботи

Метою цієї лабораторної роботи є:
- зрозуміти, що таке автоматизоване тестування і як воно виглядає на практиці;
- побачити повний життєвий цикл автотесту:  
  **середовище → сценарій → перевірки (assertions) → результат**;
- ознайомитись з базовими поняттями, які будуть використовуватись у наступних лабораторних роботах з Playwright.

⚠️ У цій лабораторній **НЕ потрібно писати код**.  
Мета — логіка тестування, а не програмування.

---

## 🧰 Інструменти

Для виконання лабораторної роботи вам знадобиться:
- Docker
- Google Chrome
- Розширення **Katalon Recorder**

---

## 🅰️ Частина A. Розгортання тестового веб-застосунку (Docker)

### 📌 Опис
Ми піднімемо навчальний веб-застосунок для практики автоматизованого тестування.  
Він містить типові UI-сценарії: логін, кнопки, динамічні елементи.

---

### 🔹 Крок 1. Запуск контейнера

Виконайте команду в терміналі:

```bash
docker run -d --rm -p 7080:5000 gprestes/the-internet:v2.6.5
```

---

### 🔹 Крок 2. Перевірка запуску

Відкрийте в браузері:

```
http://localhost:7080
```

Ви повинні побачити сторінку **The Internet** зі списком прикладів.

---

### 🔹 Крок 3. Ознайомлення з функціоналом

Вручну відкрийте сторінки:
- **Form Authentication**
- **Add/Remove Elements**

Просто подивіться, які дії доступні.  
Нічого тестувати поки не потрібно.

---

## 🅱️ Частина B. Створення автотестів у Katalon Recorder

---

## 🔹 Крок 1. Встановлення інструменту

1. Відкрийте Chrome Web Store
2. Знайдіть **Katalon Recorder**
3. Встановіть розширення
4. Відкрийте його через меню розширень

---

## 🔹 Крок 2. Створення проєкту

1. Створіть новий проєкт з назвою:
   ```
   lab01-intro-automation
   ```
2. Створіть **Test Suite** з назвою:
   ```
   SmokeSuite
   ```

---

## 🔹 Крок 3. Тест №1 — Успішний логін (Positive test)

### Сценарій
1. Відкрити сторінку **Form Authentication**
2. Ввести:
    - username: `tomsmith`
    - password: `SuperSecretPassword!`
3. Натиснути кнопку **Login**

### Перевірки
- на сторінці є повідомлення **You logged into a secure area!**
- присутня кнопка **Logout**
- користувач знаходиться в secure area

---

## 🔹 Крок 4. Тест №2 — Невдалий логін (Negative test)

### Сценарій
1. Відкрити сторінку логіну
2. Ввести неправильний пароль
3. Натиснути **Login**

### Перевірки
- зʼявляється повідомлення про помилку
- secure area недоступна
- кнопка Logout відсутня

---

## 🔹 Крок 5. Тест №3 — Add / Remove Elements

### Сценарій
1. Відкрити сторінку **Add/Remove Elements**
2. Натиснути **Add Element** 3 рази
3. Перевірити, що на сторінці 3 кнопки **Delete**
4. Видалити один елемент
5. Перевірити, що залишилось 2 кнопки **Delete**
